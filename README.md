# Korean Finance LLM Evaluation

한국어 금융 생활정보 질문에 대한 LLM 답변을 평가하고, 사전에 정의한 기준에 따라 품질을 어노테이션한 토이 프로젝트입니다.

## 1. 프로젝트 목적

금융 정보에 대한 LLM 답변이 사실에 부합하는지, 사용자가 답변을 이해하는 데 필요한 핵심 내용을 충분히 포함하는지 확인하기 위해 진행했습니다.

단순히 답변의 문장이 자연스러운지만 확인하지 않고, 각 질문에 대해 기준 답변과 필수 포함 요소, 중대한 오류 기준을 먼저 정의한 뒤 LLM 답변을 평가했습니다.

## 2. 프로젝트 개요

- 평가 분야: 한국어 금융 생활정보
- 질문 수: 15개
- 사용 모델: `Google Gemini Plus`
- 답변 생성 횟수: 질문당 1회
- 평가자 수: 1명
- 평가 방식: 수동 어노테이션
- 평가 등급: `Pass`, `Minor Error`, `Major Error`
- 진행 기간: `2026.10.15 ~ 2026.10.20`

## 3. 데이터 구성

### questions.csv

평가에 사용한 질문과 정답 기준을 저장합니다.

주요 항목은 다음과 같습니다.

- `question_id`: 질문을 구분하기 위한 고유 ID
- `question`: 사용자 질문
- `query_type`: 질문 유형
- `reference_summary`: 신뢰할 수 있는 자료를 바탕으로 정리한 기준 답변
- `required_points`: 올바른 답변에 포함되어야 하는 핵심 내용
- `major_error_criteria`: 중대한 오류로 판단할 조건

### model_responses.csv

각 질문에 대한 LLM 답변을 저장합니다.

주요 항목은 다음과 같습니다.

- `question_id`: 질문 ID
- `model_name`: 답변을 생성한 모델
- `response`: 모델이 생성한 원본 답변

### annotations.csv

LLM 답변을 평가한 결과를 저장합니다.

주요 항목은 다음과 같습니다.

- `question_id`: 질문 ID
- `label`: 최종 평가 등급
- `evaluation_reason`: 평가 근거

실제 CSV의 열 이름이 위 설명과 다르면 현재 사용한 열 이름으로 수정합니다.

## 4. 평가 기준

### Pass

답변의 핵심 내용이 사실과 일치하고, 질문을 해결하는 데 필요한 내용을 충분히 포함한 경우입니다.

문장 표현이나 순서에 차이가 있어도 사용자의 이해와 판단에 영향을 주지 않는다면 Pass로 평가했습니다.

### Minor Error

답변의 핵심 결론은 맞지만 다음과 같은 작은 문제가 있는 경우입니다.

- 필요한 부가 조건 일부 누락
- 설명이 다소 불완전함
- 사용자의 판단을 크게 바꾸지는 않는 경미한 표현 오류
- 핵심 결론과 직접 관계없는 부정확한 내용 포함

### Major Error

사용자가 잘못된 판단을 내릴 수 있는 중대한 문제가 있는 경우입니다.

- 기준 답변과 반대되는 결론 제시
- 핵심 금융 개념을 잘못 설명
- 중요한 적용 조건이나 예외를 누락해 결론이 달라짐
- 금액, 세율 또는 기준을 잘못 제시
- 질문에 대한 핵심 답변을 제공하지 못함

## 5. 프로젝트 진행 과정

1. 한국어 금융 생활정보 질문 15개를 작성했습니다.
2. 질문별로 신뢰할 수 있는 출처를 확인했습니다.
3. `reference_summary`, `required_points`, `major_error_criteria`를 작성했습니다.
4. 동일한 조건으로 LLM에 질문하고 원본 답변을 저장했습니다.
5. 사전에 작성한 평가 기준과 LLM 답변을 비교했습니다.
6. 답변을 `Pass`, `Minor Error`, `Major Error`로 분류했습니다.
7. Python을 이용해 전체 결과와 질문 유형별 결과를 집계했습니다.

## 6. 분석 결과

총 15개의 답변을 평가한 결과는 다음과 같습니다.

| 평가 | 개수 | 비율 |
|---|---:|---:|
| Pass | 15 | 100.0% |
| Minor Error | 0 | 0.0% |
| Major Error | 0 | 0.0% |
| 전체 | 15 | 100.0% |

본 데이터셋에서는 모든 답변이 사전에 정의한 필수 정보와 오류 기준을 충족하여 Pass로 평가됐습니다.

이 결과는 해당 모델의 모든 금융 답변이 정확하다는 의미가 아니라, 이번 프로젝트에서 사용한 15개 질문과 평가 기준 안에서 오류가 발견되지 않았다는 의미입니다.

## 7. 평가 사례

### 질문

`CMA란 무엇인가요?`

### 기준 답변

`자산관리계좌로 수시 입출금보다 상대적으로 높은 금리를 준다. 증권사에서 만들 수 있으며 주식 투자 전 돈을 잠시 보관하는 용도로 주로 활용`

### 필수 포함 내용

`증권사에서 개설할 수 있는 자산 관리 계좌; 높은 금리; 주식 투자 전 자본 보관 용도; 증권사; 자유로운 입출금`

### 최종 평가

`Pass`

### 평가 근거

LLM 답변이 질문의 핵심 내용을 정확하게 설명했으며, 사전에 정의한 필수 내용을 모두 포함했습니다. 기준 답변과 반대되는 내용이나 사용자의 판단에 영향을 줄 수 있는 오류도 발견되지 않아 Pass로 평가했습니다.

## 11. 프로젝트 한계

이번 프로젝트에는 다음과 같은 한계가 있습니다.

- 평가 질문이 15개로 제한적입니다.
- 하나의 LLM만 평가했습니다.
- 각 질문에 대해 한 번 생성된 답변만 평가했습니다.
- 한 명이 평가 기준 작성과 답변 평가를 모두 진행했습니다.
- 질문이 비교적 명확한 사실 확인형 질문을 중심으로 구성됐습니다.
- 평가자 간 일치도를 확인하지 못했습니다.

따라서 이번 결과를 해당 모델의 일반적인 금융 답변 성능으로 확대해 해석하기는 어렵습니다.

## 12. 향후 개선 방향

- 조건이 복잡하거나 사용자의 오해를 포함한 질문 추가
- 여러 LLM의 답변을 동일한 기준으로 비교
- 동일 질문을 여러 번 실행해 답변 일관성 확인
- 복수 평가자를 통한 평가 결과 비교
- 오류 유형을 사실 오류, 조건 누락, 과도한 일반화 등으로 세분화
- 질문과 평가 데이터 규모 확대
