# 금융 LLM 답변 평가 가이드라인 v0.1

한국어 금융 생활정보 질문에 대한 LLM 답변을 평가할 때 사용한 기준입니다. 평가자 1명이 같은 기준으로 15개 답변을 판정하기 위해 작성했습니다.

## 1. 평가 준비

질문마다 답변을 보기 전에 다음 네 가지를 먼저 작성합니다. 작성한 내용은 `data/llm_evaluation.xlsx`의 질문 시트에 기록합니다.

| 항목 | 컬럼 | 작성 방법 |
| --- | --- | --- |
| 출처 | `reference_url` | 금융회사, 공공기관, 금융 플랫폼 등 확인 가능한 자료를 사용합니다. |
| 기준 답변 | `reference_summary` | 출처를 바탕으로 질문에 대한 올바른 답변을 정리합니다. |
| 필수 포함 내용 | `required_points` | 올바른 답변이라면 반드시 언급해야 하는 핵심 내용을 `;`로 구분해 나열합니다. |
| 중대 오류 조건 | `major_error_criteria` | 사용자가 잘못된 판단을 내리게 만드는 설명을 `;`로 구분해 나열합니다. |

금융 제도는 시기에 따라 바뀌므로 기준 답변은 평가 시점의 제도를 따릅니다. 예를 들어 예금자보호 한도는 2025년 9월 1일부터 금융회사별 1인당 최대 1억 원입니다.

## 2. 판정 순서

답변 하나를 다음 순서로 판정합니다.

1. 답변이 질문의 `major_error_criteria` 중 하나라도 해당하는지 확인합니다.
2. 기준 답변과 다른 사실이 있는지 확인하고 `accuracy`를 정합니다.
3. `required_points`를 하나씩 대조해 빠진 내용이 있는지 확인하고 `completeness`를 정합니다.
4. `accuracy`와 `completeness`를 조합해 `final_label`을 정합니다.
5. `annotation_note`에 판정 근거를 적습니다.

## 3. 라벨 정의

### accuracy (사실 정확성)

| 값 | 기준 |
| --- | --- |
| `correct` | 핵심 내용이 기준 답변과 일치하고, 사용자의 판단에 영향을 주는 사실 오류가 없습니다. |
| `minor_error` | 핵심 결론은 맞지만 부가 설명에 틀린 정보가 있습니다. 사용자의 판단을 크게 바꾸지는 않습니다. |
| `major_error` | `major_error_criteria`에 해당하거나, 기준 답변과 반대되는 결론을 제시합니다. |

질문별 `major_error_criteria`에 해당하면 다른 내용이 정확하더라도 `major_error`로 판정합니다. 같은 오류라도 질문의 핵심 주제에 대한 오류인지, 부가 설명의 오류인지에 따라 결과가 달라질 수 있습니다. 예를 들어 예금자보호 한도를 이전 기준인 5천만 원으로 설명한 경우는 다음과 같이 판정합니다.

- 예금자보호 자체를 묻는 질문(Q05)에서는 중대 오류 조건에 포함되어 있으므로 `major_error`
- 다른 주제를 묻는 질문에서 부가적으로 언급한 경우는 `minor_error`

### completeness (완결성)

| 값 | 기준 |
| --- | --- |
| `complete` | `required_points`를 모두 포함합니다. |
| `partial` | `required_points` 중 하나 이상이 빠졌습니다. |

### final_label (최종 판정)

| 값 | 기준 |
| --- | --- |
| `pass` | 수정 없이 사용할 수 있습니다. |
| `need_revision` | 핵심 결론은 맞지만 오류나 누락이 있어 일부 수정이 필요합니다. |
| `fail` | 중대한 오류가 있거나 질문에 답하지 못해 그대로 사용할 수 없습니다. |

`accuracy`와 `completeness`의 조합에 따라 다음과 같이 정합니다.

| accuracy | completeness | final_label |
| --- | --- | --- |
| `correct` | `complete` | `pass` |
| `correct` | `partial` | `need_revision` |
| `minor_error` | 무관 | `need_revision` |
| `major_error` | 무관 | `fail` |

## 4. annotation_note 작성 방법

나중에 다른 사람이 보아도 같은 판정에 도달할 수 있도록 다음 내용을 적습니다.

- 맞게 설명한 핵심 내용
- 틀린 내용과 올바른 내용
- 빠진 `required_points`

예시:

> 종금형 CMA는 예금자 보호가 된다는 점은 맞지만 1인당 최고 5천만원이 아닌 1억원까지 보호됨(지난 정보 업데이트 필요)

## 5. 판정 사례

| 사례 | 판정 | 이유 |
| --- | --- | --- |
| Q01 CMA의 정의를 정확하게 설명하고 필수 포함 내용을 모두 언급 | `correct` / `complete` / `pass` | 오류와 누락이 없음 |
| Q07 종금형 CMA의 보호 여부는 맞게 설명했지만 보호 한도를 5천만 원으로 설명 | `minor_error` / `partial` / `need_revision` | 핵심 결론은 맞지만 부가 정보가 이전 기준 |
| Q15 사실 오류는 없지만 예금자보호 필요성에 대한 설명이 빠짐 | `correct` / `partial` / `need_revision` | 정확하지만 필수 포함 내용 누락 |

## 6. 반복 오류 확인

같은 유형의 오류를 발견하면 다른 답변에도 같은 오류가 있는지 전체를 다시 확인합니다. 이번 평가에서는 예금자보호 한도를 이전 기준(5천만 원)으로 설명한 답변이 Q05, Q07, Q08, Q12, Q13에서 반복되었습니다.

## 7. v0.1 재검토가 필요한 판정

이 가이드라인을 정리하면서 기준과 맞지 않는 판정 두 건을 확인했습니다. 다음 버전에서 다시 판정합니다.

| ID | 현재 판정 | 기준과 맞지 않는 점 |
| --- | --- | --- |
| A04 (Q04) | `correct` / `partial` / `pass` | 필수 포함 내용인 "직접 가입한 MMF는 환매 필요"가 빠져 `partial`인데 `pass`로 판정함. 기준대로라면 `need_revision` |
| A05 (Q05) | `minor_error` / `partial` / `need_revision` | Q05의 중대 오류 조건에 "현재 보호 한도를 5천만원이라고 설명함"이 있는데 `minor_error`로 판정함. 기준대로라면 `major_error` / `fail` |
